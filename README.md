# BattleBlocks 方块战斗

Rust + Macroquad 的单机三消战斗游戏，保留原有像素素材。传统横向/纵向三消、重力下落和连锁；7 个玩家角色对战大恶魔，支持中文和英文。

![角色选择与技能预览](analysis/character-select-preview.png)

## 安装、运行与打包

需要 Rust stable（通过 rustup 安装）、Python 3.10+ 和 pip。首次构建会从网络下载锁定依赖与校验后的字体；后续使用本地缓存。Linux 原生音频需要 ALSA 开发包和 pkg-config，例如 Debian/Ubuntu 的 `pkg-config libasound2-dev`，并需要可用的桌面图形环境。macOS 需要 Command Line Tools；Windows 使用 Rust MSVC 工具链及 Visual Studio C++ Build Tools。

```sh
# 一次完成字体工具准备、测试、原生与 Web Release 构建及打包
python3 tools/build.py

# 只构建并打包当前系统的原生版本
python3 tools/build.py --native-only

# 只构建并打包 Web；脚本仍运行原生 Rust 测试
python3 tools/build.py --web-only
```

输出在 `dist/`：

| 运行构建的系统 / 目标 | 输出 |
| --- | --- |
| macOS | `BattleBlocks.app`、`macos-<架构>.zip` |
| Windows | `battleblocks-win32-<架构>/battleblocks.exe` 与 ZIP |
| Linux | `battleblocks-linux-<架构>/battleblocks` 与 ZIP |
| Web | `web/`、`web.zip` |

原生打包针对当前构建主机，不会自动交叉编译其他操作系统。macOS和Web已实际验证；Windows/Linux打包分支已实现，但尚未在对应系统构建、游玩验收。Linux产物依赖系统图形/音频库；macOS包未签名、公证。

首次运行构建脚本后，可直接 `cargo run --release --locked` 启动。打开 macOS 的 `dist/BattleBlocks.app`，或运行 Windows/Linux 对应目录内的可执行文件；原生图像、音效与压缩音乐内嵌，无需另带素材目录。

Web本地运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist/web
```

访问 http://127.0.0.1:8765/ 。部署时上传 **整个 `dist/web/`**，包含HTML、JS、WASM、`bgm.ogg`、`crush.wav`和licenses目录。不能仅上传WASM：网页流式音乐和音效为外部文件。服务器应为WASM返回`application/wasm`；启用gzip/Brotli可减少传输。首次用户点击/按键解锁声音，符合浏览器播放规则。

`python3 tools/build.py --setup-only` 仅准备字体裁剪工具。build.rs自动扫描Rust源码中的文本、生成中文/英文字体子集；新增文字无需手动裁剪，完整字体不随游戏分发。字体来源校验SHA-256，fonttools固定4.66.1。

已手动完成Release构建时，可 `python3 tools/package.py` 重新打包，或加 `--native-only` / `--web-only`。脚本清理对应旧产物，收集当前目标实际解析的依赖许可，并生成 `dist/measurements.json` 记录字节数。

## 调试与日志

按 `~ / ～ / F1` 打开调试控制台，支持修改棋盘、双方生命／魔力、角色、强化状态和回合；AI 难度仅限开战前修改；`undo` 撤回最近操作，`undo player` 回到玩家上次交换或技能前。所有操作及连锁后果写入JSONL日志。本地支持启动 `--command` 与终端标准输入命令，网页版 `export` 下载日志。详见 [调试操作说明](docs/DEBUGGING.md)。

## 操作与技能

双方共用棋盘轮流行动。一次有效交换及全部连锁结算后换人，无效交换不消耗回合。技能通常消耗当前回合；消除增幅属于交换前的准备，每回合各可释放一次。没有合法交换时自动刷新棋盘。

敌人从其他可选角色中抽取，双方使用相同角色生命、魔力上限和技能。初始魔力为零。开战前在对手选择页确定 AI 入门／标准／进阶，开战后锁定：随机合法交换、即时收益评分、再惩罚未清除区域留给对手的机会（不预知随机补充方块）。标准及进阶 AI 会使用技能并选择目标。

点击技能或按1／2（空格释放第一技能）。范围技能在棋盘悬停预览，点击确认，再次点击技能、按同一快捷键、点击取消按钮，或右键／Esc 取消。连锁结算期间不能操作。P 暂停，R 重开，E 返回选角，M 静音，L 切换语言。技能有独立图标、释放提示、范围动画和收益数字。各类特效分别表现落雷与魔力回流、下坠陨石与冲击波、自然生长、元素聚合、武器锻造、引爆、收割、腐化、生命汲取、金币回收及角色治疗强化；标题放在棋盘上缘，避免遮挡中心。自己的回合悬停技能按钮可查看直接收益和释放后魔力（计入消耗及上限，不含后续连锁）；需选择范围的技能悬停时显示各目标收益区间，选目标时显示准确收益并高亮；转化产生的首轮三消计入预估，随机补充后的连锁未计入。此规范保存在根目录 AGENTS.md。

| 角色 | 技能一 | 技能二 |
| --- | --- | --- |
| 骑士 | 骑士冲锋（100）：选择相邻两列并清除，造成60＋所选方块伤害值总和 | 坚守回复（150）：回复最大生命值20%，清除所有纯治疗方块但不额外回血；掉落三消结算完毕后换人 |
| 精灵 | 消除增幅（35）：下一次有收益消除收益＋100% | 自然转化（60）：选择2×2变为平衡，造成25伤害、治疗10 |
| 巫师 | 雷能吸收（40）：清除两条对角线，获得魔力值总和 | 陨星轰击（160）：清除中央菱形，伤害为60＋每格伤害值一半，获得魔力值一半 |
| 哥布林 | 区域掠夺（25）：选择2×2清除，获得基础收益150% | 魔力换血（80）：回复100生命 |
| 小恶魔 | 平衡引爆（60）：清除平衡方块，每格伤害16、魔力4 | 均衡置换（60）：选择2×2变为平衡方块 |
| 角魔 | 同类收割（70）：选择一种类型清除，每格治疗2、伤害4、魔力1 | 战意转化（80）：选择2×2变为伤害方块 |
| 大僵尸 | 伤害转生（80）：纯伤害变为治疗，每格治疗3、伤害6 | 生命汲取（50）：清除所选2×2，伤害为治疗值3倍，回复2倍 |

当前行动方的侧栏有高亮边框与“行动中”标记。骑士冲锋会以缩小角色沿所选两列向下冲过，摧毁经过的方块，命中后扣血，再补充方块。

双方操作具有交换位移、消除淡出和掉落动画，结算后停顿再换人。伤害／回复飘字显示真实数值与生命前后变化，避免敌方随后回血掩盖刚才的伤害。

双方技能均可悬停查看说明、作用范围和按当前棋盘计算的收益。需要选择目标的技能显示收益区间；选中棋盘目标后给出准确预估。敌方预览使用敌方数值，查看不会触发释放。

转化形成的三消及后续连锁归行动方。第一轮按方块基础值结算，后续连锁每层＋10%，最高130%，不再按消除格数放大全部收益。精灵增幅额外＋100%，只作用于下一轮有收益消除。生命、魔力不超过角色上限；随机补充后的连锁不计入精确预估。

基础收益（生命、伤害、魔力）：平衡 `(2,4,4)`，治疗 `(6,0,0)`，伤害 `(0,12,0)`，魔力 `(0,0,12)`，治疗伤害 `(3,7,0)`，治疗魔力 `(3,0,7)`，伤害魔力 `(0,7,7)`。整体减少纯回复导致的僵局。

平衡验证使用 `cargo run --release --bin balance_probe -- 120 30000`，所有角色两两对战，交换先手；参见 [平衡报告](docs/BALANCE.md)。死亡显示原版“菜”字。

## 目录

- `src/`：游戏逻辑、角色技能与界面。
- `assets/`：直接嵌入的压缩素材、图集元数据、字体许可。
- `asset-sources/`：用于重建图集和音频的原始素材，不随游戏分发。
- `tools/`：构建、字体裁剪、素材转换、打包与内存采样。
- `analysis/`、`docs/`：内存对照实验、数据与审查记录。
- `dist/`：生成的分发包；`target/` 和 `.build-tools/` 为本机构建缓存，均不提交。

`python3 tools/prepare_assets.py`（需要 Pillow）重新生成裁剪、去重后的动画图集，验证还原画布后的帧像素一致性。BGM 重建：`ffmpeg -i asset-sources/bgm.wav -c:a vorbis -strict -2 -q:a 3 assets/bgm.ogg`。

Macroquad 0.4.16 与依赖通过 Cargo.lock 固定；网页 JS 使用匹配的 miniquad 运行时和本项目音频插件，无 CDN。字体 Noto Sans SC 使用 OFL 许可，构建自动裁剪；完整字体仅存本地缓存。

棋盘和格子背景默认用代码绘制，不加载背景图片。绘制使用按纹理分组和512顶点/768索引缓冲；文字使用有限字号与整帧预缓存。内存测量与实际限制见 [内存分析](docs/MEMORY_ANALYSIS.md)、[对照报告](analysis/memory-comparison/REPORT.md)、[字体审查](analysis/memory-comparison/AUDIT.md)。包体积由 `dist/measurements.json` 记录。

原素材美术与音频来源授权仍待核实；构建收集依赖和字体许可。macOS 包尚未签名、公证。

素材是否适合代码绘制、无损缩小验证与实测见 [素材绘制调研](docs/ASSET_RENDERING.md)。

音乐已采用流式原曲：原生CPAL输出、Lewton按包解码、128 KiB固定队列；短音效预解码并与音乐在同一输出中混合。网页音乐使用浏览器媒体播放，音效使用Web Audio。角色选择、暂停、胜负结束暂停音乐；M静音时仍推进播放位置。音频缓冲行为、8-bit试听与优化选项见 [音频调研](docs/AUDIO_OPTIMIZATION.md)。

可试听的流式播放 / 实时合成实验：`python3 tools/prepare_audio_lab.py`，启动网页服务后访问 `/audio-lab/`；原生实验见 [音频实验](analysis/audio-lab/README.md)。

### 游戏界面与设置

- 右上角依次为设置、音频、暂停／继续、`?` 方块说明；说明列出七种方块的单块基础治疗、伤害与魔力收益。
- 首页设置菜单可拖动滑杆调节0–100%音量，并切换全屏、两种窗口尺寸、语言；设置在当前运行期间保留。浏览器的窗口尺寸由浏览器管理。
- 开战采用两个独立页面：先选择自己的角色，点击“下一步：选择对手”，再选择随机或任意已有角色，确认开始对战（手动选择允许同角色对战）。重开保留指定对手，随机模式会重新抽取。
- 打开说明或设置时冻结战斗，关闭后恢复原来的暂停状态；关闭按钮和 Esc 不会误触棋盘或技能。
- 暂停面板提供继续、放弃并返回角色选择、重开和设置菜单；对局底部的快捷键文字已移除，原有快捷键继续有效。

- AI 难度只在第二步对手选择页设置，开战后锁定；设置菜单、D 快捷键和调试命令均不能中途更改，重开沿用本局难度。

### GitHub Pages

`.github/workflows/pages.yml` 会在推送 main 或手动触发时检查 Pages 是否启用，然后构建并部署网页版。当前仓库为私有仓库，GitHub API 返回现有套餐不支持此仓库的 Pages，因此尚无可访问的在线游戏地址。工作流会在 Pages 不可用时跳过部署，保留原因说明。

账户具备私有仓库 Pages 支持后，在仓库 Settings → Pages 将 Source 设为 GitHub Actions，再手动运行 “Deploy web game to Pages”。后续推送 main 自动更新网页。仓库可见性不会由工作流修改。

Windows x64 Release 由 `.github/workflows/windows-release.yml` 在 GitHub Windows runner 上构建、运行测试并打包；手动触发时填写已存在的 draft release tag，生成的压缩包和 SHA-256 校验文件会自动附加到对应 release。
