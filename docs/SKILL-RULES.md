# 技能规则

冷却 0 表示可以在一个回合内无限释放；冷却 1 表示释放后本回合不可再释放，下个自己的回合可使用；冷却 2 表示要等到再下一个自己的回合。其他条件（如资源与目标）仍须满足。技能默认结束当前回合，不结束回合的技能必须在说明中标明。

- **连续施法加价**：冷却为 0 且不结束回合的技能，本回合每已施放一次，下一次额外消耗 15 魔力；计数在回合开始清空，进入快照，费用、支付、预览与 AI 共用。当前主要影响复生、三线换位等可以同回合重复的准备技。
- **终局加压**：第 12 个完整回合后，每多一回合所有伤害＋12%、所有治疗−10%，治疗最低为原值 30%。它用于避免双方无限回血，不改变任何技能的主效果；战斗中于回合指示与棋盘之间显示下回合预警和当前累计比例。
- **共享被动**：通用被动可以由多个角色持有，例如矮人与骑士都持有「大力」＋2；角色差异放在自己的机制上，例如骑士的「笨拙」让整列交换直接消除收益 +8%，觉醒后 +18%。
- **重力相对范围与推移**：以当前下沉方向为准计算「下游／上游」。改向时，矮的「矮」被动同时翻转可操作区域、免伤区域与界面遮罩；复生沿当前重力的同行／同列向下游推移，不保留固定的上下四行。

- **消除**：让方块消失并触发方块自身效果，是三消的基础规则。
- **摧毁**：让方块消失；没有其他描述时不触发额外效果。
- **触发**：针对消失的方块产生指定效果，可与摧毁或消除组合。「摧毁并触发攻击效果」取方块的攻击效果；「摧毁并触发 50% 魔力和恢复效果」仅触发指定收益的 50%；「消除并额外触发 50% 效果」合计触发 150%。「摧毁后每个方块触发固定伤害」按指定固定值结算，而不取方块其他属性。
- **转化**：将方块变成同种或不同种方块，不触发方块自身效果。

文案不重复说明默认的消除结算，数值优先用百分比。三位新角色及现有技能已接入这些规则。技能元数据读取 config/skills.txt，角色初始参数读取 config/heroes.txt，角色说明读取 config/role-text.txt，选角尾页的档案与台词读取 config/role-lore.txt。百分比对选中方块的收益先汇总再取整。
