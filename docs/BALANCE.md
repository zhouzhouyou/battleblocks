# 角色平衡与技能预览

2026-10-15 完成一轮数值平衡。游戏、技能预览和批量对战共用棋盘、技能、随机数和收益比例规则。

## 验证方式与结果

标准AI两两对战，每个组合互换先手，不使用额外生命或魔力。旧版样本：每组合24个种子、1,008局；最终版：每组合120个新种子、5,040局，每个角色参与1,440局。

| 角色 | 旧版AI胜率 | 新版AI胜率 |
| --- | --- | --- |
| 骑士 | 51.0% | 50.8% |
| 精灵 | 63.2% | 47.4% |
| 巫师 | 14.6% | 55.8% |
| 哥布林 | 25.3% | 46.1% |
| 小恶魔 | 74.0% | 49.4% |
| 角魔 | 88.2% | 49.2% |
| 大僵尸 | 6.2% | 51.3% |

新版没有回合上限平局；中位每局36次行动，先手胜率54.2%。每局最大单次爆发伤害的90分位从旧样本480降为新版224。旧版存在明显优势与弱势角色；最终样本的整体胜率落在46.1%–55.8%。各角色仍有相互克制，完整配对结果保存在原始报告。

这些是固定AI策略的数值筛查，不能视为真人平衡结论。前后也包括AI对新收益规则的评分适配。每角色1,440局的胜率仍有抽样误差，未来根据玩家日志继续调整。

复现新版：

```sh
cargo run --release --bin balance_probe -- 120 30000
```

`balance_probe` 直接使用 `src/board.rs`、`src/content.rs`、`src/strategy.rs`，每局最多240次行动，随机补充方块正常发生。旧版原始数据为 `analysis/balance-before.csv`，新版为 `analysis/balance-after.csv`。

## 消除规则

- 取消 `max(消除格数-2, 1)` 的全局倍率，消除数量增加只线性增加基础收益。
- 一次行动内首轮100%，之后每层＋10%，最高130%。精灵技能的额外＋100%只作用于下一轮有收益消除，之后消耗。
- 所有生命、伤害和魔力先汇总，再乘比例并取整；预览使用相同规则，避免逐格取整导致误差。
- 降低普通方块治疗、适当提高伤害与魔力，减少长期靠普通回血僵持。具体基础值见 README。

## 对手技能与预估

双方技能按钮都可悬停查看完整说明。对手预估用对手生命、魔力、强化和玩家剩余生命计算。详情显示在另一侧边栏，不遮挡棋盘；固定范围高亮，可选目标显示收益区间，选目标后实时显示准确收益。转化后的首轮三消已计入，随机补充后的连锁明确未计入。预览不推进回合、不改变真实状态。

这套约定已写入根目录 `AGENTS.md`。

## 2026-11-01：矮人／骑士／牧师／修女重做

这一轮只调整矮人、骑士、牧师、修女，目标是与精灵、巫师同场时四名角色整体胜率落在 45%–55%，并让对局在 30 回合内结束。之前新增角色只有接入测试，没有经过带冷却、口袋、复制、状态与回合末效果的完整对局筛查；本轮补齐了独立工具 `src/bin/match_probe.rs`；随后 headless `--autoplay` 也接入了同一套 Session 模型，下面以它的结果为准。

### 最终参数

| 角色 | 生命 / 魔力 | 觉醒线 / 二阶段上限 | 被动与主动调整 |
| --- | --- | --- | --- |
| 矮人 | 600 / 130 | 40% / 60% | **大力**＋2（与骑士共用同一个被动身份和数值）；矮仍为下方 4 行；锻造 80 魔力、冷却 1、结束回合；跳起来 0 魔力、冷却 2、不结束回合 |
| 骑士 | 700 / 200 | 45% / 55% | **大力**＋2（与矮人共用）；**笨拙**让整列交换产生的直接消除收益 +8%，觉醒后 +18%；冲锋 100 魔力、冷却 3，摧毁相邻两列并触发攻击与魔力效果，不触发治疗；大力出奇迹 40 魔力、冷却 2，不再降低本回合消除收益；大锤 80 仍为 80 魔力、冷却 1 |
| 牧师 | 650 / 160 | 40% / 55% | 埋葬 55 魔力、冷却 1、结束回合；复生 25 魔力、冷却 0、不结束回合，插入方块并造成固定 6 伤害；心灵视界与觉醒复制栏保留 |
| 修女 | 620 / 160 | 40% / 55% | 治疗术改为双方各回复自身最大生命值的 7%（60 魔力、冷却 3）；自动恢复改为回合末 6 生命、8 魔力；友谊之奶与癫狂规则不变 |

**共享大力**：`Might` 成为矮人与骑士共同持有的被动，两者都是每个攻击方块额外＋2，不再出现同名被动两套数值。骑士的差异放在「笨拙」：整列交换产生的直接消除收益 +8%，觉醒后 +18%；这是一个百分比，而不是又一个每格＋1 的独立被动。

**连续施法加价**：冷却为 0 且不结束回合的技能，在本回合每已经施放一次，下一次额外消耗 15 魔力。当前主要影响牧师的复生，也让三线换位等准备技不能被无成本重复刷。费用显示、支付、预览、AI 和目标合法性共用 `skill_cost_in`；回合开始清空计数并进入快照。

**终局加压**：第 12 个完整回合后，每多一回合所有伤害＋12%、所有治疗−10%（治疗最低 30%）。该规则由 `Rules.round` 驱动，进入伤害、治疗、预览和 AI 结算；不是单独给某角色的补丁。这样既避免无限回血，也不改动任何技能的主效果。战斗中第 12 回合先在回合指示与棋盘之间显示下回合预警，第 13 回合起常驻显示当前累计的伤害加成与治疗衰减；帮助页保留完整规则。

**牧师魔力用途**：埋葬与复生都要支付魔力，复生连续使用还会加价；心灵视界偷来的方块不再是零成本资源。生命上限调低到 650、魔力上限 160，前中期每次埋葬都要为之后的复生留出预算。

### 独立种子结果

标准 AI、6 角色 15 个配对、每配对双向先手、48 个种子，共 1,440 局；进阶 AI 同样 48 个种子、1,440 局。原始输出：`analysis/autoplay-standard-2026-11-01.txt`、`analysis/autoplay-advanced-2026-11-01.txt`；`match_probe` 的标准样本与其逐项一致，另存为 `analysis/rework-six-*-2026-11-01.txt`。复现：

```sh
cargo run --release -- --headless --autoplay --samples 48 --seed 900000 --level 1 --roster 8,7,9,10,1,2
cargo run --release -- --headless --autoplay --samples 48 --seed 910000 --level 2 --roster 8,7,9,10,1,2
# 快速独立筛查（标准样本与上面逐项一致）
cargo run --release --bin match_probe -- 48 900000 1 8,7,9,10,1,2
```

| 角色 | 标准胜率 | 进阶胜率 |
| --- | ---: | ---: |
| 矮人 | 49.8% | 49.8% |
| 骑士 | 50.8% | 52.5% |
| 牧师 | 47.5% | 48.1% |
| 修女 | 50.6% | 47.9% |
| 精灵 | 34.0% | 36.0% |
| 巫师 | 67.3% | 65.6% |

四个被调整角色在标准与进阶样本全部落在 45%–55%。两套样本都没有行动上限平局；标准中位 18 回合，90 分位 21 回合，最长 26 回合；进阶中位 18 回合，最长 25 回合。也就是说，30 回合目标在两组固定 AI 样本内达成。

### 配对克制与未落入区间的说明

六个角色并不形成石头剪刀布式的均匀循环，仍有明显配对克制。标准样本中，矮人对骑士约 64.6%，修女对牧师约 77.1%，骑士对修女约 57.3%。这些是设计身份的直接结果，而不是无限拉扯：重击型骑士能压过缓慢回血；修女把治疗转成伤害，正好克制以慢速价值和偷取为主的牧师；矮人的持续压制又能惩罚修女缺乏爆发的回合。

精灵与巫师本轮没有改动，因此不在 45%–55% 区间，给出符合人设的说明：

- **精灵 34.0%**：精灵的强度来自斜向落点和增幅时机，固定 AI 只按当前一轮收益评分，无法为两三轮后的斜向布局投资；森林契约又持续抽走 7% 收益。人设上她是高操作、低容错的林间游击者，AI 样本低估了她的上限，不能据此把她改成站桩数值角色。
- **巫师 67.3%**：巫师是典型玻璃大炮，AI 能精确计算雷能吸收与陨星的资源循环，并自动避开低血窗口；人设上“知识就是火力”，固定 AI 比真人更容易把资源滚起来。保留 550 初始生命和觉醒前 250 魔力封印作为反制窗口，本轮没有为了压 AI 胜率而改掉巫师的核心循环。

如果要求六人全部在 45%–55%，下一步需要允许改精灵与巫师的参数；本轮遵守用户“只调整这 4 个角色”的范围。

### 无人值守 headless 复跑

上面的 `match_probe` 是独立的快速筛查器。为了让批量结果与真实游戏共用同一套模型，现在可以直接用 headless 自动对打：

```sh
cargo run --release -- --headless --autoplay \
  --samples 120 --seed 30000 --level 1 \
  --roster 8,7,9,10,1,2
```

它逐局调用同一个 `Session`，双方都由 `strategy` 决策，冷却、口袋、临时状态、连续施法加价和终局加压全部走正常结算；只跳过了动画等待和 JSONL 回滚快照。输出 CSV 包含每角色胜率、配对胜场、回合分布和先手胜率。参数与输出说明见 [调试控制台](DEBUGGING.md#无人值守批量对局)。
