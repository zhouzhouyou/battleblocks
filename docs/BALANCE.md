# 角色平衡与技能预览

2026-10-15 完成一轮数值平衡。游戏、技能预览和批量对战共用棋盘、技能、随机数和收益比例规则。

## 验证方式与结果

标准AI两两对战，每个组合互换先手，不使用额外生命或魔力。旧版样本：每组合24个种子、1,008局；最终版：每组合120个新种子、5,040局，每个角色参与1,440局。

| 角色 | 旧版AI胜率 | 新版AI胜率 |
| --- | --- | --- |
| 骑士 | 51.0% | 50.8% |
| 精灵 | 63.2% | 47.4% |
| 巫师 | 14.6% | 55.8% |
| 哥布林 | 25.3% | 46.1% |
| 小恶魔 | 74.0% | 49.4% |
| 角魔 | 88.2% | 49.2% |
| 大僵尸 | 6.2% | 51.3% |

新版没有回合上限平局；中位每局36次行动，先手胜率54.2%。每局最大单次爆发伤害的90分位从旧样本480降为新版224。旧版存在明显优势与弱势角色；最终样本的整体胜率落在46.1%–55.8%。各角色仍有相互克制，完整配对结果保存在原始报告。

这些是固定AI策略的数值筛查，不能视为真人平衡结论。前后也包括AI对新收益规则的评分适配。每角色1,440局的胜率仍有抽样误差，未来根据玩家日志继续调整。

复现新版：

```sh
cargo run --release --bin balance_probe -- 120 30000
```

`balance_probe` 直接使用 `src/board.rs`、`src/content.rs`、`src/strategy.rs`，每局最多240次行动，随机补充方块正常发生。旧版原始数据为 `analysis/balance-before.csv`，新版为 `analysis/balance-after.csv`。

## 消除规则

- 取消 `max(消除格数-2, 1)` 的全局倍率，消除数量增加只线性增加基础收益。
- 一次行动内首轮100%，之后每层＋10%，最高130%。精灵技能的额外＋100%只作用于下一轮有收益消除，之后消耗。
- 所有生命、伤害和魔力先汇总，再乘比例并取整；预览使用相同规则，避免逐格取整导致误差。
- 降低普通方块治疗、适当提高伤害与魔力，减少长期靠普通回血僵持。具体基础值见 README。

## 对手技能与预估

双方技能按钮都可悬停查看完整说明。对手预估用对手生命、魔力、强化和玩家剩余生命计算。详情显示在另一侧边栏，不遮挡棋盘；固定范围高亮，可选目标显示收益区间，选目标后实时显示准确收益。转化后的首轮三消已计入，随机补充后的连锁明确未计入。预览不推进回合、不改变真实状态。

这套约定已写入根目录 `AGENTS.md`。

## 2026-10-16：坚守回复清理治疗方块

坚守回复仍消耗150魔力、回复最大生命20%，新增清除全盘纯治疗方块。混合治疗方块保留，初次清除没有额外生命／伤害／魔力收益。掉落后的三消及连锁归骑士，全部结算后换人。预览与技能说明同步更新。

使用相同的120个种子及双向先手重跑5,040场标准AI对战，结果与前一版完全一致，骑士样本胜率仍为50.8%。原始结果：`analysis/balance-guard-clear-2026-10-16.csv`。这只说明本组固定AI回归样本未发生变化，不能据此排除真人主动使用清盘效果的平衡影响。

另通过真实游戏命令测试验证了：技能选中全部且仅选中纯治疗方块；初次清除前后生命不变、魔力不变；掉落继续由现有三消流程处理；撤回可以完整恢复施法前状态。
