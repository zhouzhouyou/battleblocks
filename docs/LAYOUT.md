# 工程目录与资源入库约定

本文件是目录职责、资源入库与特殊目录用途的权威说明。修改文件前必须遵从；目录调整时同步更新本文件、README、AGENTS 和检查规则。

## 游戏资源

`assets/` 只存放当前应该进入游戏的资源，按以下五类组织；不单独设觉醒目录。

```text
assets/
├── roles/<角色>/runtime/  普通、觉醒与独立装备的游戏图集
├── effects/              游戏特效图集
├── environment/          已接入游戏的场景与棋盘资源（目前预留）
├── ui/                   方块、界面、角色缩略图
└── audio/runtime/        游戏音乐与音效
```

普通和觉醒归属同一角色。共享配置、技能、身份、文案、本地化与资源元数据放在 `config/`。游戏代码通过明确的资源路径加载；打包工具不能复制整个制作源目录或图鉴目录。

## 正式制作源

`assets-source/` 保存当前正式资源的关键制作输入，以及对后续开发有明确参考价值的正式定稿。这些内容不进入游戏包。

```text
assets-source/
├── roles/<角色>/
│   ├── design/        当前采用的人设图
│   ├── animation/     动画源图、帧元数据、配准与调色板
│   ├── equipment/     独立装备制作输入（按需要设置）
│   └── gallery/       已明确保留的图鉴资源制作输入（按需要设置）
├── effects/<特效>/     正式特效制作程序与参数
├── environment/       暂未接入的背景制作输入
├── ui/                当前方块与界面制作输入
└── audio/             音频母版
```

此目录不接收一般候选、讨论稿、早期画风比较、用户引用参考原图或检查输出。图片采用无损 WebP；保留动画帧序、时长、调色板和配准数据，确保制作工具可复现当前资源。传送方块的 `animation/atlas.webp` 是实际重排打包输入，按生产用途保留。

## 特殊目录

| 目录 | 职责与边界 |
| --- | --- |
| `gallery/` | 未来图鉴资源。目前图鉴尚未实现，不加载、不随游戏发布；当前保存明确为图鉴保留的修女立绘。一般讨论稿不能以图鉴名义入库 |
| `src/` | 游戏代码，遵守现有模型与表现分层 |
| `docs/` | 当前规则、用户决定、文字讨论与对参考图的文字说明 |
| `tools/` | 可复用的制作、构建、分析和检查工具 |
| `experiments/` | 可复现的独立实验代码、说明与必要输入，不随游戏发布 |
| `analysis/` | 暂留的历史文字与结构化评估记录；其长期保留粒度待决定，不随游戏发布 |
| `licenses/` | 授权与第三方来源 |
| `.local/` | 本地候选、用户参考原图、预览、拼图、截图、录屏及新增运行输出，禁止入库 |
| `target/`、`dist/`、`logs/`、`.build-tools/` | 编译、发布、日志与本机缓存，禁止入库 |

图鉴功能正式接入时，将实际需要的运行文件迁入 `assets/`，并更新资源注册与打包清单。实验的新输出放 `.local/` 或已忽略的实验结果目录，不能混入实验源码。

## 入库与历史边界

- 只保留当前正式资源与关键制作输入。未采用讨论稿、被替代的图片、preview、contact sheet、比较图和录屏，从当前树及本工作分支的历史一起移除。
- 文字讨论允许入库，包括用户原话及未采纳的人设方向；所有引用的参考原图均不入库，只保留文字说明。正式人设图是本项目制作成果，与用户提供的参考原图有区别。
- 前期画风讨论稿及其文档引用不保留；唯一全局美术规范见 [高细节像素画规范](art/ART-DIRECTION.md)。
- 路径、资源名与文档不附加迭代版本号，不堆叠历史副本。提交记录表达修改过程。
- 所有允许跟踪的二进制及 SHA-256 列入 `config/asset-manifest.json`。确认采用新资源后才更新清单；提交与构建前运行 `python3 tools/check_repository.py`。
- README 必须链接本文件，AGENTS 必须要求遵从本文件。新增特殊目录必须先在此说明用途、入库与发布边界。

## 暂留待决定

- `assets-source/roles/demon/` 的原版备用角色，以及 `assets-source/environment/` 的未接入背景：需要确认后续使用价值。
- 音乐 WAV 母版：需要确认是否长期保留编辑输入。
- 内存实验所带的完整字体与音乐：需要确认是否继续保留该实验工程。
- `analysis/` 下的 CSV、JSON、日志与文字报告：本轮保留文字及结构化结果，待决定保留粒度。

## 历史清洗范围

在隔离仓库中重写本工作分支，再同步到本 Worktree。主目录当前检出的 `main` 和远端不会自动改写，因此共享对象库占用不能代表清洗后分支大小。体积审计以清洗分支可达对象及隔离仓库压缩体积为准。
