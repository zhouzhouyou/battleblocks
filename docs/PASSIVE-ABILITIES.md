# 独立被动与觉醒能力（2026-10-27）

被动不再从一段本地化说明中解析名称。`src/abilities.rs` 提供稳定的 `Passive` 身份、名称、独立说明、实时状态与 `replaces()` 替换关系；`passives(hero, awake)` 返回当前阶段实际拥有的条目。战斗信息栏、选角页和实际消耗/收益使用同一套身份。

| 角色 | 初始被动 | 觉醒后的变更 |
| --- | --- | --- |
| 骑士 | 列阵；战技训练（消除收益+6%） | 新增冲锋专精（伤害+25%）、守护节制（坚守150→80魔力） |
| 精灵 | 林间穿行；森林契约（消除收益-7%） | 新增精灵之力（消除伤害额外+25%基础值） |
| 巫师 | 奥术转化；魔力封印（250上限） | 魔力解放（400上限）替换魔力封印；新增陨星节制（160→140魔力） |
| 哥布林 | 废物回收 | 新增掠夺专精（技能直接与首轮消除伤害+30%） |
| 小恶魔 | 平衡亲和（每平衡方块额外4伤害）；元素回流（额外2魔力） | 平衡共鸣（额外6伤害）替换平衡亲和；元素回流保留；新增爆裂专精（引爆每格12→14伤害） |
| 角魔 | 血怒（35%血线、消除伤害+25%） | 沸血（50%血线）替换血怒 |
| 大僵尸 | 血肉施法（每缺1魔力支付2生命） | 血肉转化（1生命抵2魔力）替换血肉施法；新增血祭（生命代付技能的直接伤害+20%） |

骑士坚守始终回复当前阶段生命上限的20%，属于技能本身的治疗规则；因此单独新增的是降低魔力消耗的被动，不把生命上限换算重复当作额外增益。

## 交互

- 双方侧栏以最多两行、两列显示当前被动，每项有代码绘制的简易图标和独立悬浮区域。略缩小战斗角色预览，技能卡片位置和大小不变。
- 血怒/沸血显示未触发或+25%，奥术转化根据当前魔力上限显示转化/正常治疗，血祭注明必须由生命代付触发，不伪装成全局伤害加成。所有说明均为当前阶段数值。
- 悬浮显示名称、独立效果、条件状态；替换型被动额外说明替代了哪项。觉醒后不再保留旧被动条目。
- 选角第二页拆分初始被动，第三页逐项显示觉醒新增/替换能力，保留“新增/替换”提示。技能详情使用当前阶段说明，不再为每个技能附加整段角色觉醒说明。
- 图标复用现有代码绘制风格，并增加容量锁、解锁、训练和资源回流等标记；无新增图片资源或Rust依赖。
- 觉醒状态仍是快照的来源；回滚、重开与切换角色后重新派生条目，不保存会滞留的第二份能力状态。

- 83项游戏测试、51项对战工具测试通过，既有音频测试1项忽略。新增覆盖旧能力恰好被保留或替换一次、条目无重复、容量/消耗/代付身份与实际规则一致、实时条件状态、恢复初始阶段不残留升级。
- 重构前后使用同一种子700000–700023、标准AI、双向先手进行1,008局回归；完整输出逐字一致，见 `analysis/passive-identities-regression.csv`。这次重构没有重新调整平衡参数。
