# 调试控制台、命令行与战斗日志

按 **~ / ～ / `** 或 **F1** 打开控制台，Enter 执行，Esc 关闭。打开时冻结战斗并接管输入，输入 `mp`、`restart` 等命令不会触发游戏快捷键。关闭后恢复原来的暂停状态。`move`、`cast`、`resolve` 执行后自动关闭控制台，让动画和连锁正常结算。

## 命令

坐标从 **1 到 8**，顺序是 **x y**，左上角为 `1 1`。方块类型：`0` 平衡、`1` 治疗、`2` 伤害、`3` 魔力、`4` 治疗＋伤害、`5` 治疗＋魔力、`6` 伤害＋魔力。

| 命令 | 效果 |
| --- | --- |
| `help` | 查看完整命令表 |
| `status` / `board` | 查看双方状态／输出棋盘 |
| `tile 3 4 2` | 将第3列第4行改为伤害方块 |
| `board load <64个0..6整数>` | 按行载入完整棋盘 |
| `resolve` | 结算当前棋盘已有的三消与后续连锁，归当前行动方 |
| `shuffle` | 生成没有初始三消、且有合法交换的新棋盘 |
| `seed 42` | 设置后续随机流，配合 shuffle 重现布局 |
| `hp player 500` / `hp enemy 200` | 修改生命，范围为0到角色上限 |
| `mp player 300` / `mp enemy 100` | 修改魔力，范围为0到角色上限 |
| `hero player 2` / `hero enemy 6` | 替换角色，生命恢复到上限，魔力和强化清零 |
| `buff player bonus 1` | 设置下一次有收益消除的附加增幅，每单位＋100%（调试范围0..10） |
| `buff player armed on` | 设置三线换位状态；off 关闭。也支持 enemy |
| `turn player` / `turn enemy` | 修改当前行动方，保留双方各自强化状态 |
| `ai 0` / `ai 1` / `ai 2` | 仅开战前可设置入门／标准／进阶，对局中拒绝修改 |
| `pause on` / `pause off` | 修改战斗暂停状态 |
| `move 2 1 2 2` | 在玩家回合执行交换，必须满足正常交换规则 |
| `cast 1 3 4` | 玩家释放第一技能，目标为第3列第4行，遵守正常魔力和回合规则 |
| `cast 2` | 释放第二技能；无目标时默认中心 `4 4` |
| `undo` | 回到最近一次行动或调试修改前 |
| `undo player` | 回到最近一次玩家交换／技能前，撤回其后敌人行动与调试修改 |
| `restart` | 重开，清除回滚历史，日志保留 |
| `export` | 本地版保存当前日志；网页版下载 JSONL |

角色编号：`0` 骑士、`1` 精灵、`2` 巫师、`3` 哥布林、`4` 小恶魔、`5` 角魔、`6` 大僵尸。

修改棋盘不会立即自动消除，方便逐格设置测试场景；完成后执行 `resolve`。连锁尚未结算完时，棋盘、回合、角色和强化修改会被拒绝，可先 `undo` 回到行动前。生命、魔力和暂停允许在待结算阶段修改；AI 难度只允许开战前设置，对局中锁定。

## 回滚

保留最近256个行动快照。一次交换／技能及其连锁属于同一个行动；无效交换会写入日志，不占回滚快照。快照保存棋盘、双方角色与数值、行动方、待结算区域、结算计时、AI档位、暂停、双方强化状态和随机数状态；临时目标选择和视觉特效在回滚时清除。

`undo player` 跳过敌人行动和调试修改，定位最近一次玩家战斗操作。日志追加 `rollback` 事件并标明撤回的行动编号；原有记录不会删除，后续行动编号也不会重用。重开或重新开始选角后的战斗会清除快照历史。

## 本地终端

直接运行可执行文件，可从标准输入逐行发送同一套命令。`--command` 可重复指定启动命令，按顺序逐帧执行；有启动命令时直接进入骑士对战。操作命令仍要求正确回合和连锁已结算，启动命令不会替你等待整段连锁。

```sh
./dist/BattleBlocks.app/Contents/MacOS/battleblocks --debug --log ./logs/test.jsonl
```

```sh
./dist/BattleBlocks.app/Contents/MacOS/battleblocks \
  --command 'hero player 2' \
  --command 'mp player 800' \
  --command 'cast 2'
```

`--debug` 启动时打开控制台，`--log <路径>` 指定日志文件。该程序仍会显示游戏窗口。

## 日志

本地版自动写入 `~/Library/Logs/BattleBlocks/session-<时间戳>-<进程号>.jsonl`，每个事件立即 flush。启动时控制台／终端输出真实路径。网页版保存当前页面会话记录，执行 `export` 下载 `battleblocks-session.jsonl`；刷新前导出。

每行是独立 JSON，包含 `seq`、`action`、会话时间 `time`、`event`、`actor`、`detail`、完整 `before`／`after` 状态。事件覆盖命令、双方有效／无效交换、技能扣费及直接效果、每轮连锁、棋盘刷新、回合切换、战斗结束和回滚。骑士冲锋另有 `skill_hit` 命中事件，`skill` 记录扣费与待命中伤害，`skill_hit` 才记录实际扣血；快照中的 `charge_damage`、`charge_remaining` 保存待命中效果和动画进度。通过前后状态可计算实际生命／魔力变化，包括上限截断后的真实收益。

`board[y][x]` 和快照 `pending` 采用代码索引0..7；交换和技能目标的日志说明采用与命令一致的1..8坐标。日志会包含补充方块后的棋盘，可按 action 关联一次操作及其全部连锁。

## 验证

`cargo test` 覆盖命令边界、完整棋盘载入、撤回历史和随机流恢复。构建 debug 可执行文件后运行 `python tools/check_debug_console.py`，通过真实游戏的标准输入验证玩家／AI交换、技能、连锁、棋盘修改、完整快照回滚与JSONL格式。
