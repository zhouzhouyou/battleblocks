## 造型锁定

- 男性矮人、橙色胡须、灰铁半盔、皮围裙、蓝色腰布、敦实宽厚，保持 E-A 普通形态的铁匠气质。
- 身体高度是骑士等正常角色的一半。比较时必须同地平线、同像素尺度；身体不含头盔额外突起、武器、脚下的书。
- 用户指出的右手／非持锤手必须完全空着，自然垂放；手中及手指附近不得有副武器、盾牌、工具、刀柄、灰色横杆或其他不明握柄。另一只手持锤。腰带与围裙配件不能穿过手掌或造成正在握物的错觉。这不是需要二选一的装备设计，而是必须修正的生成错误。
- 同一把方头铁锤刻有清楚的角形符文。觉醒前符文为不发光的暗色刻痕；觉醒后原符文红色发光，可有暖亮核心，但不把整把铁锤替换成新武器。
- 普通／觉醒保持同一身体、脸、头盔、头发、胡须、护甲、围裙、腰布与装备轮廓。**觉醒不增加护甲，不长头发，不增加羽冠或红色马鬃，不增高或变壮。**
- 觉醒的身体外观变化仅为锤子发光；仇恨之书是独立的场景／角色附属层，垫在脚底，不是角色长高。

## 用户能力设定（设计决定，尚未写入游戏）

### 普通被动

1. **大力**：每个攻击方块造成的伤害额外加 **N**。N 保持待定，由后续平衡确定；不随意写死。攻击方块的混合类型适用范围与技能清除适用情况待规则阶段确认。
2. **矮**：技能和交换只能在棋盘下方四行进行；敌人在上方四行进行交换造成的伤害对矮人无效。

棋盘 UI 按从上至下第 1–8 行标记，基础可操作区域为第 5–8 行。跨界交换、技能作用格与目标锚点的边界语义，以及后续连锁伤害如何归属，需要在战斗实现前明确，不能擅自推定。

### 主动技能

1. **跳起来**：使用后，本回合交换或技能的范围增加一行，魔力消耗较低；具体消耗待平衡。根据用户描述，这应作为本回合准备动作设计，避免使用后立即结束回合而无法享受扩展；是否可重复、是否消耗行动及每回合次数仍待明确。
2. **锻造**：将一个 2×2 正方形区域内的方块转化为锤子（攻击方块）；消耗待定。选区仍受角色当时可操纵范围约束，后续三消按最终规则实现。

### 觉醒被动：仇恨之书

- **最新覆盖（2026-10-28）：只有同一本厚重的仇恨之书，随 80% / 60% / 40% 血量阶段逐级增厚，不再堆多本。** 外观必须厚实，不能像薄册或杂志；封面、封底与身份保持相同，主要增加中间纸页厚度。
- 每个增厚等级让角色可操纵范围增加一行，最多三级。根据当前血量实时调整；回血后同一本书变薄、角色下降、额外范围实时减少，不按历史最低血量永久保留。
- 视觉预览采用含等号的阈值：`B = [HP/maxHP ≤ .8] + [≤ .6] + [≤ .4]`，B 现在表示同一本书的增厚等级，而非书的本数；仅觉醒后启用。正式计算使用整数比较以避免浮点边界；此项是便于评审的阈值解释，后续需随规则测试固定。
- 预览范围解释为从底部向上扩展：`min(8, 4 + B + J)` 行，J 表示本回合跳起来是否生效（0／1）。这是本轮动画／范围演示的具体解释，不作为跳跃叠加规则已通过的声明。
- 非觉醒与觉醒血量 >80%：不垫书；≤80%：一本厚书、一级；≤60%：同一本更厚、二级；≤40%：同一本最厚、三级。
- 封面与纸页顶面托住双脚，人物整体随同一本书增厚而垫高；身体自身高度不变。回血时书变薄、人物平稳下降；不凭空多出第二本、第三本。

### 越界反馈

玩家点击不可操纵区域时，角色对话框显示：

> 该死，我够不到

不能确认交换或技能目标。反馈不花费资源、不改变棋盘，不重复刷屏；台词消失后可再次触发。最终接入时覆盖鼠标与键盘选目标。

## 动画设计 v1

| 动画 | 帧／节奏提案 | 行为与约束 |
| --- | --- | --- |
| 普通待机 | 4 帧，单帧 180ms，约 720ms 一轮 | 脚底固定，肩胸起伏约 1 逻辑像素，胡须随动，空手轻微收放；锤子重量感优先，暗符文不亮 |
| 觉醒待机与符文 | 4 帧，180ms 一帧 | 身体沿用普通待机；锤子原刻痕暗红→红→亮红／暖核心→红，低频脉冲，不闪烁整个身体，不改变护甲或头发 |
| 仇恨之书出现／增厚 | 一次性事件，约 300–450ms／等级 | 最新方案：一本厚书首次垫到脚下；后续只增加同一本书纸页厚度，封面／封底不增加；角色随顶面升高；不翻开、不写字、不做开合动画 |
| 回血变薄 | 一次性事件，约 300–450ms／等级 | 同一本书纸页减少、顶面降低，角色随之下降；回到零级才整本收走；生命与范围状态实时更新 |
| 够不到 | 一次性，气泡约 1.8 秒 | 看向不可操纵格，空手短伸后收回，显示原台词；无多余物件与副武器 |
| 跳起来（扩展准备） | 起跳／落地提案 4–6 帧 | 这是主动技能反馈，和仇恨之书常驻垫高分开；范围增加只持续当前回合，不擅自定义消耗与重复次数 |

动画概念预览需要校准帧间一致性，不能把生成图直接宣称为生产用 sprite sheet。身体与书分层，符文与锤头对齐；任何导出帧保持脚底锚点、像素尺度一致，画布容纳同一本书最厚时的高度。封皮不能随纸页被整体拉伸变形。

### 素材分离与替换约定（用户明确要求）

- **不得把矮人与书绑定成唯一素材。** 矮人身体／符文、书物件／增厚动画分开保存，书的动画中不包含矮人像素。
- 书拥有独立底部锚点与顶部承托面；角色使用脚底锚点。角色位移只读取书面高度变化，不能依赖当前矮人某一张图的固定裁切或身体尺寸作为最终接口。
- 书封面、纸页、封底在动画设计上独立，增厚主要改变纸页，封皮保持自身尺寸。后续更换矮人图，不需要重绘书或重做书的动画；只需校准角色自己的脚底锚点。
- 合成 GIF／视频仅是评审效果预览，不是正式角色贴图，不可以取代独立源图与独立书动画。允许预览用具体裁切拼合，但不能把它当成生产管线或固定接口。
