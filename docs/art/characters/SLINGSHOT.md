# 弹弓手

## 身份与玩法

Issue #49 的弹弓手为独立新角色，稳定 ID 13，位于新角色页。玩法名「弹弓手」，人物名奥林·铜扣，称号「铜扣老匠」，为侏儒老工匠。拥有轻型与重型弹弓两个主动技能；普通及觉醒参数由 `config/projectiles.txt` 维护。初始生命 650、魔力 160，当前收益升级来自技能配置。轻型满力能到第四列，重型可到棋盘远端，觉醒后重型技能内解锁炼金爆弹选择，实心弹承担远射。

用户明确要求「我只是让你用老角色的图片」「本质上还是一个新角色」。老哥布林 ID 3 的现行技能为区域掠夺、魔力换血，被动为废物回收，觉醒增加掠夺精通；角色档案见 [哥布林](GOBLIN-LEGACY.md)。

## 当前人设方向

用户在四张人设候选图中选择「B」，采用侏儒老工匠方向。图中造型细节按本节整理，后续精修依照角色评审规范逐项确认。

- **轮廓与面貌**。年长男性侏儒，矮圆结实的身形、宽鼻、浓白眉、短白须与鬓角，棕色软工作帽上架圆形黄铜护目镜。神态带工匠的专注与自信。
- **普通形态**。深青蓝卷袖工作衫、赭黄厚皮围裙、深棕补丁长裤与厚底短靴，护臂采用皮革和黄铜。腰间配石弹袋、工具与折叠重型弹弓，手持小型木叉轻型弹弓。
- **觉醒形态**。沿用同一人物面貌、服装与身体比例，通过站稳发力的姿势、展开的黄铜滑轮重弓，以及弹丸内发光的炼金药芯表现强化。重弓采用单手柄、上方双叉、弹性带与皮革弹兜组成的 Y 形结构。
- **材质与配色**。高细节像素插画，主色为赭黄皮革、深青蓝布料、暖棕木材和黄铜，白眉白须形成面部识别点。细节集中于护目镜、围裙扣具、护臂及弹弓机构。
- **性格基调**。严谨、有工匠自尊、喜欢展示手艺，把射击视为作品验收。人物背景与台词从 `config/role-lore.txt` 读取，中英文共同维护。

候选图片与提示词保存在本地 `.local/art/slingshot/`，图像采用情况依照 [角色评审规范](../CHARACTER-REVIEW.md) 确认。

## 制作基准

完整人设图遵循现有矮人、骑士的制作参考形式，包含同尺度的角色正面、侧面、背面，普通与觉醒对照，平静、得意、恼火三种表情，以及帽与护目镜、围裙、护臂、弹袋、炼金弹丸和轻重弹弓的分解结构。三视图使用统一头身比例和鞋底基线，服装扣具、围裙背带、腰间物件及折叠重弓的位置跨视图对应。

后续角色动画采用 384×384 生产帧、脚底锚点 (192,336)、单帧可见高度约 300～320 像素，按项目统一的全高度展示；侏儒的矮圆感通过宽厚躯干与头身比例体现。普通与觉醒共用人物造型和像素密度，制作目标为共享 64 色、二值透明、无抖动，光源位于左上。觉醒差异落在重弓机构、弹丸药芯及发力姿势。

完整人设图与生成提示词分别保存在本地 `.local/art/slingshot/model-sheet.png` 和 `.local/art/slingshot/model-sheet-prompt.md`，用于造型评审与后续制作核对。

## 背景与被动

奥林·铜扣替矿镇修理升降机四十年，退休后把滑轮与弹性机构的经验做成两把弹弓。他严谨、好胜，爱展示手艺，也会替村里的孩子修玩具。完整中英文背景、特质与七句台词统一维护在 `config/role-lore.txt`。

普通形态不设被动。觉醒强化名为「滑轮增压 / Pulley overdrive」，通过提高发射初速体现更大的力气，强化不额外产生资源事件。

## 弹丸选择与觉醒

普通与觉醒均保留轻型、重型两个技能。觉醒后选择重型弹弓时，可在瞄准面板选择实心弹或炼金爆弹，也可按 Tab 切换。

- 滑轮增压使轻、重弹弓的初速提高 15%。轻型命中触发 75% 方块效果，重型触发 60%，两形态比例相同。
- 炼金爆弹质量为实心弹的 1.75 倍，在相同发射能量下，初速除以质量比的平方根。爆弹飞行 0.8 秒自动结束飞行并引爆，提前落地则立即引爆，额外触发范围内未直接命中方块的 60% 效果，半径 1.75 格。满力配合约 22° 的最远射程仰角，爆炸范围可以勉强覆盖最远一列；提高仰角会让空爆位置升高并缩短水平距离。
- 两类弹丸共用重型技能、70 魔力费用与冷却。轻型消耗 30 魔力。两把弹弓均冷却 2 回合，释放后的下个自己回合仍在冷却，再下个自己回合恢复。

弹丸类型属于有类型的瞄准输入，预览、实际释放、AI、提示、日志和回滚共用规则。AI 为每种弹丸保留候选，再以真实补充连锁与后续回合收益排名。爆弹的范围优势与较重的弹道共同构成选择依据。

玩家从左侧向右发射，敌方从右侧向左发射。命中、弹道、操作区与爆炸共用实际坐标，AI 更换推演视角时保留物理发射方向。

## 当前游戏素材引用

正式角色使用完整持弓动画，源图为 `assets-source/roles/slingshot/animation/` 下的 `normal-idle-source.webp`、`awake-idle-source.webp`、`normal-cast-source.webp` 和 `awake-cast-source.webp`。普通与觉醒待机、施法各 12 个独立姿势，共 48 帧，384×384 帧、6×8 图集、共享最多 64 色、二值透明、脚底锚点 (192,336)。源图使用真实透明背景，生产导出沿用 160 的 alpha 阈值。轮廓采用深色像素边，禁止浅色背景残留及贴纸状白边，导出后须在深色背景核对。选角缩略图直接绘制同一图集的普通首帧。

`tools/prepare_slingshot_art.py` 复用现有角色制作流程并生成 `src/sprites/slingshot.rs`，供角色页与战斗 HUD 共用。放弃的空手分层、关节部件及其试验图只保存在 `.local/`，均不入库。

用户决定暂缓双手跟随瞄准、拉力和回弹。后续重启时先验收原人设的臂长、臂围、手掌和弹弓比例，再接入关节与实时手位。当前角色独立播放完整动画，操作区承担弹弓输入与轨迹预览。

轨迹按真实解析抛物线采样，以等弧长像素点绘制，飞行时叠加像素拖尾与带高光弹丸。觉醒重型爆炸复用现有 `assets/effects/ember-blast.webp` 的第 7～20 帧（从零计数），以圆形 UV 遮罩适配真实爆炸半径，命中后播放一秒。操作区随加宽画布提供，弹道与碰撞规则见 [弹射能力](../../ARCHITECTURE.md#弹射能力)。
