# 弹弓手

## 身份与玩法

Issue #49 的弹弓手为独立新角色，稳定 ID 13，位于新角色页。暂名「弹弓手」，人物外形与背景待后续定稿，现行介绍只描述技能操作。拥有轻型与重型弹弓两个主动技能；普通及觉醒参数由 `config/projectiles.txt` 维护。初始生命 725、魔力 160，当前收益升级来自技能配置。轻型满力能到第四列，重型可到棋盘远端，觉醒后重型解锁爆炸。

用户明确要求「我只是让你用老角色的图片」「本质上还是一个新角色」。老哥布林 ID 3 的现行技能为区域掠夺、魔力换血，被动为废物回收，觉醒增加掠夺精通；角色档案见 [哥布林](GOBLIN-LEGACY.md)。

## 临时素材引用

普通、觉醒及缩略图共用老哥布林当前正式资源，直接引用现有图集与动画元数据。图片只承担新角色的占位外观。美化时为弹弓手制作独立素材，并更新自身的注册与缩略图映射。

弹弓拉伸、弹珠与爆炸暂用通用几何表现。操作区随加宽画布提供，弹道与碰撞规则见 [弹射能力](../../ARCHITECTURE.md#弹射能力)。
