# Hammer-smash  · 棋盘重击

用于骑士「大锤80」：用户于 2026-11-03 确认在棋盘随机命中的 2×2 区域中心播放一次重击；侧边骑士沿用现有施法动作。不新增锤子实体、不修改石中剑或角色外观。复制得到相同技能时沿用同一表现。

改编来源与完整许可见 [PixelFX 声明](../../../../licenses/pixelfx/NOTICE.md)。`hammer-smash.rs` 是离线 Rust 改编源，保留原效果的加速挥击光迹、两道地面波、力场壳、碎石与扬尘层次；不依赖 JS，不使用原库人偶／动作系统／字体。种子固定且独立，不接触游戏随机流或结算。

遵循全局 E 方案：硬像素簇、灰紫石材阶梯、暖金主帧和暗红尾迹；只让整簇淡出，避免随机碎点；烟尘使用克制的分层透明。原版 2 秒压缩为 0.9 秒，落点主帧为 0.4 秒，与既有 CLEAR_TIME 对齐。每格 64 逻辑像素，特效 1:1 播放，中心不随双方位置镜像，在棋盘边缘裁切。

- 生产图集：`assets/effects/hammer-smash.webp`，192×128／帧，28 帧，7 列，1344×512，30 fps，锚点 (96,88)，无损 RGBA。
- 第 12 帧（0.4 秒）命中；第 27 帧为空；不会重复到四个方块各播放一次。
- 用户反馈「方块消失早了」「没有方块被粉碎的动画吗」后修订：命中前四格保持原尺寸与不透明度，停止提前缩小淡出；命中后将施法时捕获的实际方块纹理各切为 4×4 块，碎片向外／上方散开并在 0.36 秒内淡出，和重击闪光、碎石、扬尘叠加。碎片只属于表现，不影响重力、收益或回滚。
- 运行时位置与裁切：`src/effects/hammer_smash.rs`；图集只在 GUI Session 中载入。
- `atlas.json` 为设计元数据，`contact.webp` 与 `board-preview.webp` 是棋盘材质合成评审，未模拟游戏重力和完整 UI。
- 不修改固定 80 伤害、随机落点、方块收益、费用、冷却、回滚或模型时序。

重建：使用 `.build-tools/python-path.txt` 指定的 Python 执行 `tools/prepare_hammer_smash.py`。工具用 rustc 编译此源，输出 RGBA 帧，再导出无损 WebP，检查像素逐字节回读、空末帧和所有帧的空边界；所有评审源均留在此目录，不进入游戏包。运行时只读取生产 WebP。
