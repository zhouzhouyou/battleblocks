# 角色美术评审规范与档案索引

全局画风与制作要求见 [ART-DIRECTION.md](ART-DIRECTION.md)，目录和资源归属见 [LAYOUT.md](../LAYOUT.md)。本页维护评审方法与当前权威档案，不记录阶段计划或已完成任务流水。

## 评审方法

1. 每次聚焦一位角色，先提出至少四种有实质差异的设计；差异来自轮廓、性别、年龄、服装、性格或觉醒方式，不能只换色。
2. 每个候选说明普通形态、觉醒形态、标志物和角色介绍；用户未提供介绍时提醒补充，不从参考图推定传记。
3. 用户明确选定方向后再制作人设图与动画；选定方向不代表所有生成细节通过。违反明确设定的地方标为待修，不反过来改变用户设定。
4. 当前角色档案保存权威设定、用户必要原话与正式资源入口；提示词和参考图文字说明可作为持续制作依据保留，失效提案不得标为现行规则。
5. 候选图、用户参考原图、预览和验收输出只放本地。只有正式采用且有持续用途的资源进入制作源或游戏目录。
6. 普通与觉醒的动作边界遵从全局美术规范及各角色当前档案；旧角色普通资源原样保留，觉醒动作保持细像素。
