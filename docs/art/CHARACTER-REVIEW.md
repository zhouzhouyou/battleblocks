# 角色逐人评审

全局方向见 [ART-DIRECTION.md](ART-DIRECTION.md)。14 位角色的职业／种族意象已选定，性别、年龄、体型、打扮、个性与觉醒设计允许继续探索。历史名称不锁定最终性别；例如矮人战士可以是女性。

## 评审流程

1. 每次聚焦一位角色，先给至少 4 份实质不同的设计稿，全部同时对比。
2. 每份包含普通形态、觉醒形态、标志物；可组合不同稿的特征。
3. 候选差异来自性别、年龄、轮廓、身体重心、服装、性格、文化或觉醒方式，不能只换色。至少探索两个性别表达，除非用户另有指定。
4. 先选意象与轮廓，再修订装备、配色、普通／觉醒连续性；只有用户明确选定才能记录为通过。
5. 评审页面的点选为临时偏好；用户在对话中确认后才落盘，不能用演示按钮伪称已保存或已通过。
6. 概念稿通过后，再生成、校准并验收符合网格的生产资产；不把生成图片的视觉近似当成尺寸或色数合格。
7. 用户于 2026-10-29 要求候选阶段只保存图片与记录，不自动提交；2026-10-30 明确要求提交本次牧师文档更新。
