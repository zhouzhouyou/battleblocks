# 老巫师技能特效 v2 · Lightning Strike 与扩张冲击波

2026-11-04 用户修订原文：「能进化成 Lightning strike 的效果吗？另外陨石爆炸之后也是冲击波才对，方块逐渐消失，特效不用太快」。v1 源和预览保留，此目录为当前修订，待视觉评审。

## 闪电

改为 Lightning Strike 式蓄电：地面投影法阵、从上往下生长的先导通道、粗暖白主雷柱、两侧分叉、分三次脉冲放电、落点细支电弧与余电。较弱的 X 形电网保留原技能的两条对角线作用范围；不因视觉增强引入伤害、治疗或新状态。命中格位依次退场，随后蓝色光点回收至施法者的魔力条。

## 陨星

保留单颗灰紫切面、带熔融裂纹和火尾的陨星，飞行放慢。落地白色主帧后不再出现团状火球爆炸，改为带暖白前缘、阶梯空气层和灰尘的圆形压力波，附一圈较淡的后续波和冷却碎屑。波到达哪一层目标，那层原方块才逐渐缩小／淡出；40 格目标仍由模型提供，未命中的格位不被销毁。

## 时序与表现分离

- 两招整段约 2.8 秒：约 0.9 秒主命中，波／电流传播后逐层退场；10 fps 像素图集，方块透明度在游戏帧循环中连续变化。
- `src/effects/wizard_timing.rs` 由离线渲染和游戏共用，冲击波半径、到达时间和逐格淡出不会分别编写。
- 模型仍一次结算原目标，不重复发放收益，不逐格复制结算规则。GUI 缓存施法前目标贴图，并延后已有重力动画；等待全部目标退场后才播放原有下落路径。未改变方块类型、技能数值、费用、资源上限、随机数或结算顺序。
- 前摇和下落等待属于 GUI `Presentation`；Headless 不创建这些特效。普通消除和其他技能时序不变。觉醒等模型等待会延后主命中，撤销／重开同时清除缓存与表现等待。
- 角色、书本和角色动作 WebP 均未修改。

生产素材仍为 `assets/effects/wizard-lightning.webp`、`wizard-meteor.webp`，两者各 512×512／帧、29 帧、6 列、3072×2560，10 fps，第9帧 0.9秒命中，末帧为空，不循环。GUI 资源初始化时载入，避免首次施法临时解码跳过前摇。保持全局 E 方案的整数像素、阶梯颜色和克制光晕。
