## 雷能吸收（技能1）

蓝白电弧沿两条对角线逐步传导，命中时 16 个格位同步闪亮、分叉放电。随后从实际命中格位飞出蓝色光点，向当前施法者的魔力条回收；不画成攻击对手的雷击。维持现有 60 魔力费用、目标选择与魔力收益规则。

生产素材 `assets/effects/wizard-lightning.webp`：512×512／帧，16 帧，4 列、2048×2048，20 fps，第 8 帧 0.4 秒命中，0.75 秒空末帧。魔力回收路径在游戏中根据施法方向与模型提供的格位绘制，到约 1.08 秒结束。

## 陨星轰击（技能2）

一颗带熔融裂纹与火尾的阶梯灰紫岩石从棋盘左上方斜落中央；暖白主爆帧、火团、菱形扩张冲击波、石屑和扬尘依次退场。命中闪光使用模型给出的实际中央菱形目标（当前 40 格），不再逐格重复小火球；不改变 50% 伤害／魔力触发、额外 60 伤害、费用或觉醒规则。

生产素材 `assets/effects/wizard-meteor.webp`：512×512／帧，24 帧，6 列、3072×2048，20 fps，第 8 帧 0.4 秒命中，1.15 秒空末帧。

## 共同规范

两招遵循全局 E 方案：1:1 最近邻、硬像素边缘、受控阶梯光色、固定视觉种子。离线 Rust 源参考 PixelFX `lightning/lightning-strike` 与 `fire/meteor` 的分叉电弧、冷却通道、燃烧岩石、火尾和冲击层次，完整许可与出处在 `licenses/pixelfx/`。不引入原库人物、骨骼或字体。

表现从同一个 Session 消除通知获得命中时刻；命中前保持目标方块完整，觉醒导致模型等待时特效不提前命中。致命一击仍可自行完整退场。复用炎爆的通用表现时钟，撤销与重开清理；玩家、敌方与复制施法者共用目标坐标和本人的魔力回收方向。

图集随 GUI 资源初始化载入，不在施法帧中临时解码，避免首次施法因慢帧跳过蓄力；Headless 不载入。设计源和评审图不进入包，只打包 assets/ 下生产 WebP。

用 `.build-tools/python-path.txt` 指定的 Python 执行 `tools/prepare_wizard_spells.py` 重建；工具检查无损像素回读和空末帧。两项均经过三轮渲染、目视检查和调整。`*-preview.webp` 是固定棋盘上的合成评审，未模拟完整 GUI 的清盘、重力、命中格位闪光或飞向侧栏的魔力回收，不是游戏录像。
