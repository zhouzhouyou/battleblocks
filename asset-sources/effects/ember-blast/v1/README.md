# 炎爆术 v1 · 整盘火焰爆发

用户于 2026-11-04 要求：「接下来做炎爆术（精灵火法师的技能），这可以是个全屏特效，笼罩整个棋盘。另外，补充睡觉的ZZZ特效。」本轮只修改表现，不修改火精灵、矮人或其他角色 WebP，也不补角色动作帧。

## 设计与生产

中央双旋聚焰 → 全棋盘暖白主爆帧 → 向外扩张的火焰团、冲击波与深红火舌 → 稀疏余烬、退场。完整覆盖共享 8×8 棋盘的 512×512 逻辑像素，包括四角；不覆盖角色、文字、技能牌。E 方案下保持硬像素簇、阶梯明暗、暗红边缘与克制暖白高光，固定视觉种子，不使用战斗随机流。

离线 Rust 渲染源借鉴 PixelFX `fire/fire-ring` 与 `explosions/big-explosion` 的聚焰、扩张火团和冷却余烬层次；构图为本项目的整盘爆发。声明见 `licenses/pixelfx/`。生产图集 `assets/effects/ember-blast.webp`：512×512／帧，22 帧、6 列、3072×2048，15 fps，1:1 最近邻绘制；第 6 帧为 0.4 秒主爆，末帧透明，不循环。三轮渲染与目视调整后形成当前 v1，待用户视觉评审。

主爆跟随 Session 的首次实际全盘消除通知；对手觉醒暂缓结算时停留在聚焰阶段，方块不提前缩小／淡出。致命一击使模型不再清盘时，表现自行播放完毕。首次消除后，表现时钟独立于施法栏计时，确保退场不被截断。撤销／重开清理时钟。未改变施法条件、满魔／觉醒加成、清盘不触发方块收益、伤害、状态或回合逻辑。

用 `.build-tools/python-path.txt` 指定的 Python 执行 `tools/prepare_ember_blast.py` 重建此图集及睡眠 ZZZ。工具验证无损像素回读、主爆全盘覆盖及空末帧。`board-preview.webp` 为固定棋盘上的特效合成，未模拟完整 GUI 的清盘／重力，不是游戏录像；`contact.webp` 为缩略逐帧评审。
