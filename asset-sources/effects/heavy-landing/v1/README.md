# Heavy landing v1 · 矮人「跳起来」

2026-11-04：用户要求先提交大锤80，再继续开发矮人跳起来。大锤提交为 `b02a440`。本效果单独开发、待用户视觉评审。

从 PixelFX `impacts/heavy-landing` 改编为离线 Rust 渲染：两道错开的低矮尘环、脚边灰紫阶梯尘簇与少量弹跳碎石。遵循 E 方案的像素簇、整数坐标和克制半透明，不使用原库人物／骨骼／字体，不制造裂地伤害、魔法光环或新增装备。版权与 MIT 许可见 `licenses/pixelfx/`。

- 表现位置是当前施法角色的脚底锚点，玩家和敌方独立；觉醒时落点随仇恨之书顶面，不移动或破坏书。
- 0.12 秒起跳，最高抬起 14 个逻辑像素，0.65 秒落地；扬尘在落地后播放 0.7 秒。高度给魔力条保留空间，不改变人物像素密度。
- 起跳从现有帧配置读取普通／觉醒施法的首帧（四次重复以保持无呼吸缩放），不在表现代码中锁定帧号；落地转回待机，避免通用施法后续帧的抡锤光迹。不修改角色 WebP，新增动画帧由独立工作负责。
- 前后两层分别在人物绘制前后播放，近层只覆盖脚边；裁切到侧栏和被动行上沿，不遮住文字、技能牌或棋盘。
- 跳跃有独立表现时钟，紧接着锻造不会让空中的角色瞬间落下；撤销、重开清除临时动画。Headless 不加载纹理、不创建该时钟。
- 保留当前零魔力、冷却 2、不结束回合、增加可达行数等规则；不延迟技能生效，不阻止下一次合法操作。

生产图集 `assets/effects/heavy-landing.webp` 为无损 RGBA：176×80／帧，每层 22 帧，7 列，每层占 4 行，前后两层共 1232×640；30 fps，落点 (88,60)，末帧透明。原始渲染源与预览不进入游戏包。

用 `.build-tools/python-path.txt` 指定的 Python 执行 `tools/prepare_heavy_landing.py` 重建。源文件通过 `src/effects/landing_motion.rs` 与游戏共用跳跃轨迹。工具逐字节验证 WebP 像素、空边界和空末帧；`dwarf-preview.webp` 为现有矮人贴图与特效的合成评审，不是完整游戏录像。
